# Infinite Canvas Agent 功能清单

> 更新日期：2026-07-14
> 适用分支：`feature/codex-agent`

## 当前范围

Agent 模式目前只集成在智能画布中。普通画布不会显示或依赖 Agent 模式。

Agent 以 Codex App Server 为执行引擎，由 Canvas Agent 管理产品历史、画布上下文、生成任务、审批和界面状态。所有画布操作通过受限的原生工具或 `window.SmartCanvasAgentApi` 窄桥接完成。

## 1. Agent 对话面板

- 智能画布内的浮动 Agent 窗口。
- 支持拖动、调整窗口大小、关闭和恢复。
- 流式显示 Codex 回复。
- 支持 Markdown、代码块复制、折叠和展开查看。
- 工具调用和命令执行会合并成可折叠摘要。
- 显示处理状态、耗时和完成时间。
- 支持停止正在执行的任务。
- 页面刷新、关闭或重新打开后，可以恢复正在运行的后台任务。

## 2. 画布理解与查询

Agent 可以读取：

- 当前选中的节点。
- 当前视口附近的节点。
- 整个画布摘要。
- 节点详细信息。
- 节点之间的连接关系。
- 按名称、类型或内容搜索节点。
- 当前图片和视频生成队列。
- 单个生成任务的状态、结果和错误。

Agent 能理解“这张图”“选中的节点”“右边那几个节点”等上下文，不需要用户提供内部节点 ID。

## 3. 引用和附件

- 将选中的图片、视频、提示词节点加入输入栏。
- 按顺序显示为 `图1/ref_1`、`图2/ref_2`。
- 支持在输入中使用 `@图1` 引用素材。
- 支持粘贴图片到 Agent 输入框。
- 支持缩略图预览。
- 双击引用可以定位到来源节点。
- 支持一键清空引用。
- 提示词节点作为文本上下文使用。
- 图片、视频会转换为临时本地引用，不在用户项目目录写入临时文件。

## 4. 创建画布节点

Agent 可以创建：

- 图片、视频等媒体节点。
- 提示词节点。
- 文本节点。
- 循环节点。
- 只创建、不立即运行的生图节点。
- 只创建、不立即运行的视频生成节点。

批量创建时会自动排列，避免所有节点堆叠在同一位置。

## 5. 图片生成

Agent 可以：

- 按当前智能画布默认配置直接生成图片。
- 指定数量、提示词、比例、分辨率、模型和 Provider。
- 使用图片、视频或提示词节点作为参考。
- 创建待运行节点，或者直接提交生成。
- 将生成任务交给后台运行，聊天结束后节点仍继续生成。
- 将结果写回对应画布节点。
- 保留生成日志、开始时间、结束时间和耗时。
- 精确控制生成数量，避免一次请求返回多张造成额外节点。
- 将明确的比例同步到节点设置，例如 `9:16 + 2K` 不会显示成 `1:1`。
- 查看失败状态并重试。

Agent 生图必须使用 Infinite Canvas 已配置的 Provider，不会绕过画布设置调用 Codex 内置的 `$imagegen`，避免重复生成或重复扣费。

## 6. 视频生成

Agent 支持：

- 创建视频生成节点。
- 直接提交视频任务。
- 指定提示词、比例、分辨率、模型和 Provider。
- 使用图片或视频作为参考。
- 后台轮询任务并写回结果。
- 保存任务 ID、运行状态、错误和耗时。

对于模糊的视频请求或较大的批量任务，默认先询问一次关键参数。如果用户明确说“直接运行”“使用默认值”或“不用问”，则使用当前画布默认配置执行。

## 7. 节点编辑与整理

Agent 可以：

- 修改素材显示名称。
- 将一个或多个节点整体移动到明确坐标、指定节点旁边、全画布节点群四侧或当前视口空位。
- 将单图/视频节点统一为标准视觉尺寸；多图节点按一个容器处理，保留内部图片比例并恢复原生宫格，不强套单图尺寸；提示词、循环和智能分组可恢复默认尺寸。
- 按节点真实外框进行横向、纵向或自动/指定列数的宫格排列。
- 在模糊的多节点整理请求中先分析尺寸差异、周边占用和可用方向，给出整理建议并等待确认。
- 递归收集选中节点的全部上下游，以选中根节点为锚点在附近空位紧凑收拢，并按上游在左、下游在右的层级布局整理；碰撞按各节点真实外框判断，不要求整块包围盒塞进视口，也不会受全画布远端节点拖拽。
- Agent 对已完成媒体节点执行移动、缩放或排列后，打开中的画布以服务端新布局为准实时更新，同时保留本地生成完成计时和图片结果并集。
- 将节点分组。
- 取消分组。
- 删除节点。
- 撤销最近一次 Agent 操作。
- 定位并聚焦到相关节点。

重命名默认只修改素材显示名，不会修改真实文件名、真实文件路径或源节点标题。

移动和排列只修改节点的 `x`、`y`；用户明确要求统一或恢复尺寸时额外写入或清除节点显示 `w/h`。这些操作不会改变节点 ID、连接 ID、连接数据或素材文件。

## 8. 智能放置

支持三种放置范围：

- `viewport`：以发送消息时看到的智能画布区域为准。
- `global`：根据整个画布内容安排位置。
- `node`：相对某个选中或引用节点放置。

具体行为：

- 有明确输入引用时，将引用保存为节点的“上游输入”，但不绘制连接线。
- 没有显式引用、但选中了画布节点时，会在选中区域右侧寻找空位，并建立输入连接。
- 自动检查节点碰撞，避免新节点重叠。
- 用户在 Agent 思考期间平移或缩放画布，不会改变该轮已捕获的位置语义。

## 9. 生成任务管理

- 查看生成队列。
- 查看单个任务的详细状态。
- 重试失败或中断任务。
- 取消仍处于本地排队状态的任务。
- 服务重启后继续轮询已有 Provider 任务 ID 的任务。
- 防止中断任务被静默重复提交，避免重复扣费。

任务一旦已经交给上游 Provider，系统不会伪装成“已取消”。

## 10. 删除与撤销保护

- 删除节点和撤销 Agent 操作始终属于高风险操作。
- 即使开启自动执行，也需要用户确认。
- Agent 操作前会保存私有画布快照。
- 可以撤销最近一次 Agent 修改。
- 删除节点时同步清理相关连接、分组成员和输入节点引用。
- 使用删除墓碑机制，避免旧的服务器快照把刚删除的节点重新合并回来。

私有快照存放在画布数据之外，不改变原有画布保存结构。

## 11. 执行审批

Agent 操作大致分为：

- 查询操作：通常直接执行。
- 创建、移动、整理等低风险操作：可根据当前审批策略直接执行。
- 昂贵或不明确的生成任务：先进行一次简短确认。
- 删除和撤销：始终要求高风险确认。
- 用户明确说“直接运行”“使用默认值”或“不用问”时，使用当前画布默认配置执行。

## 12. 会话与历史

Agent 使用独立的 Canvas Agent 历史系统：

- 按“当前画布 → 工作目录 → 对话”管理历史。
- 新建对话。
- 切换历史对话。
- 查看当前目录或全部目录的对话。
- 按添加时间或最近使用时间排序。
- 页面刷新后恢复消息、工具结果和画布操作结果。
- Codex 原始线程无法恢复时，保留当前 Canvas Agent 对话，并创建新的执行线程继续。
- 支持“无目录”模式进行聊天和纯画布操作。

历史数据存储在：

```text
~/.codex/infinite-canvas-agent/
  history.sqlite
  panel-history/
```

历史不会存放在用户项目目录中。

## 13. 工作目录管理

- 为当前画布选择不同工作目录。
- 手动输入绝对路径。
- 从预设目录和直接子目录中选择。
- 添加、隐藏和排序工作目录。
- 隐藏目录不会删除对应对话。
- “无目录”模式下可以操作画布；需要读取或修改项目文件时，Agent 会要求先选择工作目录。

工作目录预设存储在：

```text
~/.codex/infinite-canvas-agent/workdir-presets.json
```

## 14. 偏好记忆

Agent 可以保存简短的全局偏好，例如：

- 默认排列方向。
- 常用图片比例。
- 常用生成方式。
- 用户希望减少确认。
- 常用工作习惯。

全局偏好存储在：

```text
~/.codex/infinite-canvas-agent/preferences.md
```

偏好保存在项目之外，不修改画布存档格式。

## 15. 异常处理

- 单个节点不存在时跳过该项，继续处理其他有效节点。
- Provider 名称无法识别时明确报错，不会静默切换到其他平台。
- 即梦历史同步延迟会继续轮询，不会立即把节点标记为失败。
- 审核失败、参数错误、余额不足等会转换成简洁中文提示。
- 后台任务、线程或页面恢复失败时，会保留已有对话并给出提示。
- 内部上下文、Provider 列表、工具协议和节点内部 ID 不会显示在普通聊天内容中。

## 16. 上游兼容与安全边界

- Agent 功能只存在于 `agent/`、`static/js/codex-agent-panel.js`、`static/css/codex-agent-panel.css` 和 `/api/codex-agent/*` 等隔离区域；`main.py` 只保留必要依赖装配。
- 智能画布集成通过 `smartAgent*` 辅助函数和 `window.SmartCanvasAgentApi` 完成。
- 不重写原有选择、拖拽、平移、缩放和快捷键 `Z` 的交互逻辑。
- 不改变原有画布保存和加载结构。
- 不修改原始节点 ID、连接 ID 或连接数据结构。
- 不为 Agent 命名操作修改真实素材文件名或真实文件路径。
- 不向普通聊天界面暴露内部工具协议、隐藏上下文或内部节点 ID。

## 17. 当前主要入口

前端面板：

```text
static/js/codex-agent-panel.js
static/css/codex-agent-panel.css
```

智能画布桥接：

```text
window.SmartCanvasAgentApi
```

后端接口统一位于：

```text
/api/codex-agent/*
```

智能画布入口：

```text
static/smart-canvas.html
```

普通画布 `static/canvas.html` 不加载 Agent 面板。

## 18. Canvas Skills 与上下文优化

- `/` 命令由后端统一注册，前端仅负责搜索和渲染。
- `/批量任务` 是规范名，`/批量处理` 保留为兼容别名；当前不创建任务节点。
- 整理、命名、提示词、生成、分析和批量规划已拆成 Canvas 专用 Skills。
- Canvas Skills 只由画布 Agent 按任务加载，不安装为桌面版 Codex 的全局 Skills。
- 每轮只注入命中的一个 Canvas Skill，纯聊天不附带画布偏好、工具列表或 Provider 列表。
- Provider 和模型列表通过 `get_generation_settings` 按需查询。
- 完整节点和连线只保存在服务端快照，浏览器请求只保留视口、选中 ID 和少量选中节点几何信息。

## 19. Canvas Revision

- 每份画布都有 Agent 私有的单调 Revision，不修改原画布存档结构。
- 每轮发送快照和 Canvas 查询结果都包含 Revision。
- 全画布、批量、删除和撤销等操作会校验发送时 Revision。
- 发现过期画布时返回结构化冲突，不执行旧计划。
- 目标明确的低风险操作仍会在实时画布上重新解析目标，无效项单独跳过。
