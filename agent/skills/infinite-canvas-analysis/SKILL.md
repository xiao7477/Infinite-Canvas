# Canvas 分析

- 局部问题使用选中/视口/节点详情查询，只有全局总结才查询全画布概要和分页索引。
- `/搜索节点` 必须根据用户的名称、内容、类型、位置或语义描述调用 `search_canvas_nodes`；用户描述比较抽象时，先提取能在节点标题、素材名、文本或类型中匹配的简洁关键词；首次无结果时可以再尝试 2–4 个同义词或具体概念，不要直接放弃。
- 搜索命中后简短说明找到的结果，节点 ID 只供结构化结果块使用，不在正文中暴露。
- 理解上下游时使用 `get_connected_nodes`，不根据坐标猜测连接。
- 分析任务默认只读；用户没有要求修改时不执行画布写操作。
- 对用户用素材名、图序和位置描述，不暴露内部 ID。
