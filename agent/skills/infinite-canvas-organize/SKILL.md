# Canvas 整理

- 先查询用户指定的选中、引用、视口或全画布范围，不猜测节点。
- 用户明确说出位置、尺寸或排列方式时直接执行；说“直接整理”“按建议执行”时使用当前建议或下述默认值。
- 多选节点但需求只有“整理一下”等模糊表达时，必须先调用 `get_layout_context`，只提出建议，不调用写工具。建议包含：是否统一大小、横排/纵排/宫格、原地或移动到哪个空位。给一个推荐方案和最多两个备选方案，并用一个简短问题确认。
- 建议统一大小的默认阈值是媒体显示长边差异超过 15%。2–4 个且单行空间足够时优先横排；狭长竖向空间优先纵排；5 个以上或单轴空间不足时优先宫格。
- `resize_nodes` 的标准规则：横图/视频宽 520，竖图/视频高 440，另一边按原比例；方图 440×440。多图节点视为一个容器，默认只清除人工 `w/h` 并恢复原生宫格，不套用单图标准；提示词、循环、智能分组恢复内容对应的默认尺寸。参数写在 `options.size_mode/media_size/non_media_size`。
- `arrange_nodes` 支持 `options.mode = horizontal|vertical|grid`。宫格未指定 `options.cols` 时自动取接近平方的列数。排列间距按节点外框计算，不按中心距离计算。
- `move_nodes` 通过 `options.placement_scope = node|global|viewport`、`options.side` 和可选 `options.anchor_node_id/anchor_ref` 表达目标位置；也支持明确 `options.x/y`。多节点作为整体移动并保持内部相对位置。
- 用户要求整理节点树时，先用 `get_node_tree` 确认完整上下游，再调用 `arrange_node_tree`。默认包含全部上游和下游，以选中根节点为锚点在附近空位紧凑收拢；上游在左、下游在右、同层纵向展开。空位判断按各节点真实外框进行，不要求整棵树的矩形包围盒完整塞进当前视口，也不因全画布远端节点把树搬远。
- 组合“统一大小并排列”时，把 `options.size_mode` 放进同一次 `arrange_nodes` 调用，保证一次撤销能恢复整个操作。
- 移动、缩放和排列不修改节点 ID、连线、素材数据或真实文件。
- 全画布、大批量和节点树改动遵循当前审批策略；若工具返回 `no_space`，说明空间不足并给出其它方向，不强行覆盖节点。
